양끝이 고정된 줄에 하중을 걸면 가운데가 얼마나 처질까요? 첫 실습에서는 PINN으로 줄의 모양을 구합니다. 두 번째 실습에서는 같은 2 W 히터를 알루미늄 판 중앙에 놓았을 때와 모서리 가까이에 놓았을 때의 온도 분포를 FNO로 예측합니다.

## 실행 환경

행사에서 안내받은 링크로 Brev에 로그인해 GPU를 시작하세요. 인스턴스가 `Running`이 되면 JupyterLab을 열고 `00_Start_Here.ipynb`의 첫 셀부터 `Shift + Enter`로 실행합니다. 첫 노트북에서 GPU와 자동미분이 동작하는지, 열판 데이터가 준비됐는지 확인할 수 있습니다. 별도 Brev GPU 환경에서 실행하려면 [환경 설정](environment/README.md)을 참고하세요.
